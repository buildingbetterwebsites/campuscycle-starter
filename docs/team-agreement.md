## Members, roles and pairs

<table width="100%"><tr></tr><tr><td>

**Guidance.** Write a member next to each of the six roles, and the member they work in a pair with.
Use first names or GitHub usernames only, because your repository is public. A role means that you
make sure the work happens. Every member still writes code and documents.

The default for each team size:
- **Six members:** each member holds one role. There are three pairs: one for each of your two user
  tasks, and one for the content model with releases.

roles writes "alone" in the last column. Your team may share the roles differently. Then write how,

## When a pull request is done

<table width="100%"><tr></tr><tr><td>

**Guidance.** A pull request changes the code. A document such as this one needs no pull request:
you commit it straight to `main`. The list below is the course's default. Keep it or change it, and
add your own rules. A teammate's review is optional, so the list says when your team asks for one.

**Example of a rule of your own:** A change to the reservation form is tried once with a full event
before it is merged, because a full event must never accept a reservation.

</td></tr></table>

The author of a pull request merges it when all of this is true:

- The author tried the change on its preview, at a narrow width too when something visible changed.
- Its AI note is filled in.
- The starter's checks have finished. The author read what they say, and fixed what a red check found
  when that was possible.
- A change to the content model has its migration. Only the content-model pair creates migrations.

We ask a teammate for a review when the author is not sure of a change.

## The AI note

<table width="100%"><tr></tr><tr><td>

**Guidance.** The first paragraph below is the course's rule: keep it. Then say how your team checks
what an AI tool wrote before you use it. A pull request made with GitHub's **Revert** button needs no
note.

**Example of a note:** *What I asked AI:* how to show "Full" on an event with no seats left. *What I
checked:* on the preview, I reserved the last seat with made-up details. The event then showed
"Full", and the form refused a second reservation.

</td></tr></table>

Every pull request has the section *AI note: what I asked AI, and what I checked*, under that exact
heading. The note is one or two lines and has two parts: *What I asked AI* and *What I checked*. When
no AI tool was used, the note says "No AI used".
